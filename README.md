# Fruit Recognition using KNN (Correlation Distance)

## Cấu trúc thư mục
```
fruit_recognition_project/
│
├── dataset/                 # Thư mục chứa ảnh từng loại hoa quả (tạo thủ công)
├── train_knn_correlation.py  # File huấn luyện mô hình
├── requirements.txt          # Các thư viện cần cài đặt
└── results/                  # Lưu mô hình và kết quả sau khi chạy
```

## Cách chạy
```bash
pip install -r requirements.txt
python train_knn_correlation.py
```

Sau khi chạy, kết quả sẽ được lưu trong thư mục `results/`.
